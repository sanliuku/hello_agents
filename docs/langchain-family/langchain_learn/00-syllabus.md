# LangChain 源码解剖教材 · 总纲

> 对象：`langchain` v1（源码 `libs/langchain_v1/langchain/`）
> 学习者：你（已手写过 ReAct / Plan-and-Execute / Reflection，会 LangGraph 基础）
> 学习方式：**我讲一块源码 → 你手敲一块代码 → 你验证 → 你做破坏实验 → 你过自检题**

---

## 一、这本教材和官方教程的区别

| | 官方 Quickstart | 本教材 |
|---|---|---|
| 出发点 | "怎么用" | "**它内部长什么样**" |
| 代码 | 复制粘贴即可跑 | **要求你手敲**，因为敲的过程会暴露你不懂的地方 |
| 验证 | 看输出对不对 | 看**你能预测输出**，以及**改坏了会不会报错** |
| 落点 | 会调用 API | 能读 `factory.py`、能写 middleware、能 debug |

一句话：**官方教程教你当用户，本教材教你能改它。**

---

## 二、学习契约（请先同意这四条）

1. **不复制粘贴。** 每章代码请手敲。敲错、报错、修好——这是学习本身。
2. **先预测再运行。** 每段代码运行前，先写下你预期会打印什么。不符就是认知缺口，记下来。
3. **每章必做破坏实验。** 至少故意改坏一次，看懂报错。不做的章节视为未完成。
4. **每章写一条"认知修正"。** 格式固定：`我原本以为…实际上…`。

## 三、12 章地图

> 章号 = 你手敲的文件序号。`ch` 指章节文档，`.py` 指对应代码。

| 章 | 标题 | 源码主要落点 | 你会得到的能力 |
|---|---|---|---|
| **0** | 地图与环境 | `libs/*` 包结构 | 知道 `langchain` / `langchain-core` / `langgraph` 各自是什么，环境能跑 |
| **1** | 一次 invoke 的真相 | `agents/factory.py` 图装配段 | 能画出 `create_agent` 编出的那张图（含节点名与边） |
| **2** | Message 解剖 | `langchain_core/messages/` | 能逐字段解释一次工具调用往返的 4 条消息 |
| **3** | Model 层 | `chat_models/init_chat_model.py` | 能解释 `"openai:xxx"` 字符串如何变成实例，`bind_tools` 干了什么 |
| **4** | Tool 层 | `langchain_core/tools/` | 能解释 `@tool` 如何从函数生成 schema，能诊断"模型为什么不调它" |
| **5** | State 与 Reducer | `langgraph/graph/message.py` | 能自定义 state 字段，能解释 `add_messages` 的特殊语义 |
| **6** | 记忆与 checkpointer | `langgraph/checkpoint*` | 多轮对话、`thread_id` 隔离、`get_state_history` 时间旅行 |
| **7** | 结构化输出 | `agents/structured_output.py` | 能说清 tool 策略 vs provider 策略的取舍 |
| **8** | Middleware 上：钩子地图 | `agents/middleware/types.py` + factory 节点装配 | 能说出 6 个钩子在图的哪一步执行、谁包住谁 |
| **9** | Middleware 下：写有用的 | 同上 + `HumanInTheLoop` | 能写"动态改 prompt + 工具白名单 + 审批"三件套 |
| **10** | 流式 | `langgraph` stream | 能选对 `stream_mode`，能把 token 级输出接出来 |
| **11** | 测试与可观测 | `test` + LangSmith | 能给 Agent 写单元测试，能定位"哪一步走偏" |
| 结课 | 三版对照项目 | 全栈 | 产出可写在简历上的对照报告 |

## 四、每章统一模板（你按这个节奏走）

```
① 本章你会得到什么        一句话，可验收
② 源码解剖               真实文件 + 真实代码片段 + 它在干什么
③ 你敲这段               ~30-60 行，带"为什么这么写"的逐行说明
④ 你应该看到             期望输出（先预测，再对照）
⑤ 三个破坏性实验         故意改坏，看报错
⑥ 自检题 3 道            答不上来就别进下一章
⑦ 承上启下              下一章为什么自然接上
```

## 六、本教材的诚实边界

- 源码引用基于 `master` 分支的 `libs/langchain_v1`（v1 线）。你本地装的若是 v0.x，文件名与内部结构会不同（见第 0 章的版本判定法）。
- 我**没有在你的机器上实机运行**过这些代码（本机 pwsh 执行被沙箱拦住），所以每章的"你应该看到"是按源码逻辑推导的期望值。第一次跑若有差异，优先怀疑版本，再怀疑我。
- 模型名会漂移。凡是出现具体模型名的地方，一律以你 `.env` 的 `LLM_MODEL_ID` 为准。
